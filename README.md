# ✅ Todo List App

A clean and simple Todo List web application to help you organize your tasks efficiently.

---

## 📸 Preview

> A minimal, responsive task manager built with HTML, CSS, and JavaScript.

---

## 🚀 Features

- ➕ Add new tasks quickly
- ✅ Mark tasks as complete
- 🗑️ Delete tasks
- 💾 Tasks saved in local storage (persist after page refresh)
- 📱 Responsive design — works on mobile and desktop

---

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| HTML5 | Structure |
| CSS3 | Styling |
| JavaScript | Logic & Interactivity |

## ⚙️ Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)
- No installations required!

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/Pragati-coders/Todo-List.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd Todo-List
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   # Or use Live Server in VS Code
   ```

---

## 💡 How to Use

1. Type your task in the input field
2. Press **Enter** or click the **Add** button
3. Click the checkbox to mark a task as ✅ complete
4. Click the **🗑️ delete** icon to remove a task
